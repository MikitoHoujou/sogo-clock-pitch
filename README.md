# Sogo Clock Wall — pitch

Wild Tame's interactive pitch for the projection on the Sogo Yokohama clock wall: seven
directions (A–G), seasonal versions, an hour-by-hour day plan and concept frames. English and Japanese.

**View:** https://wild-tame-co-ltd.github.io/sogo-clock-pitch/ · 日本語: `ja.html`
(works once Pages is turned on for this repo).

## Change the page with Claude

1. Open Claude Code: claude.ai/code in the browser, or the Code tab in the Claude desktop app.
2. Choose this repo, `Wild-Tame-Co-Ltd/sogo-clock-pitch`.
3. Ask for the change in plain words, for example "add a winter version to the seasons section"
   or "make direction G's Japanese greeting list longer".

Claude reads `CLAUDE.md`, edits `src/page.html`, keeps the Japanese page in step, rebuilds and
saves the change here. To build by hand: `python3 tools/build.py`.
